配置驱动设计

所有差异项抽象为 WORKBENCH_CONFIGS 配置对象（standard / jiuJiao / huaChuang 三套），页面加载与版本切换时由 applyVersion() 统一渲染标题、nav 按钮、业务支持中心、个性化按钮区，无需改动框架代码即可新增版本。

不变项与可变项

不变：三栏布局、左侧工作空间与用户栏、输入框结构（加号 + AI开关 + @提及 + 模型选择 + 发送）、右侧面板模块。
可变：标题、nav 按钮集合、业务支持中心、个性化按钮区，均为配置开关。

标准工作台框架结构

左栏（固定）

  • 品牌标题（可配置）
  • 开启新对话
  • 工作空间按钮（可配置）
  • 工作空间列表
  • 用户栏 / 铃铛 / 设置

中栏（核心）

  • 业务支持中心（可选）
  • 会话头部 + 成员
  • 会话消息流
  • 输入框：加号菜单 + 个性化按钮（可配置） + AI开关 + @提及 + 模型选择 + 发送

右栏（固定）

  • 会话摘要
  • 当前任务
  • 成果物
  • 关联原子模型
  • 来源
