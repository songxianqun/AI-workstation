## 一、现状与痛点诊断

### 1.1 当前左侧结构（图 3）

| 元素 | 说明 | 问题 |
|---|---|---|
| 「默认文件夹」 | 所有新会话自动归档到这里 | 文件夹无意义、层级冗余 |
| 用户自建文件夹 | 每个会话都自动挂一个文件夹 | 会话 ≈ 文件夹，1:1 关系导致文件夹爆炸 |

| 共享会话 | 邀请他人进入可查看被共享的会话 | 共享入口与会话/文件夹边界不清 |

## 二、核心设计原则

| # | 原则 | 含义 |
|---|---|---|
| P1 | **会话 ≠ 文件夹** | 会话是内容，文件夹是容器；1 个会话不必 = 1 个文件夹 |
| P2 | **系统文件夹消失** | 取消"默认文件夹"、取消"自动化/订阅"自动建文件夹 |
| P3 | **文件夹只来自用户主动创建** | 用户不建 = 不出现；减少噪音 |
| P4 | **最近 > 全量** | 默认展示 3~5 条最近活跃项，想看全部点右侧面板展开 |
| P5 | **活跃排序：用户操作 > 系统动态** | 用户主动发起的会话排最前，订阅/自动化的新信息排其后 |
| P6 | **新消息强提醒** | 订阅、自动化、被@、协作邀请必须有红点/未读数提示（对标飞书 aily） |

## 三、左侧面板重构方案

### 3.1 双区布局（"项目 / 最近"模型，参考图 2）

```
┌─ 左侧面板 ─────────────────────────────────┐
│ [🔍 搜索会话 / 任务 / 订阅]                 │
├─────────────────────────────────────────────┤
│ 📌 置顶（用户钉住的会话，0~N 条）           │
│   ├─ 置顶会话 A  ················  ● 2     │
│   └─ 置顶会话 B  ················          │
├─────────────────────────────────────────────┤
│ ⏱ 最近（默认 5 条，点击"查看全部"展开）     │
│   ├─ 🧑‍💼 刚刚发起的会话（用户操作优先）      │
│   ├─ 🤖 自动化有新消息（订阅/定时任务推送）  │
│   ├─ 🔔 订阅更新 · 10 分钟前                │
│   ├─ 💬 同事 @ 我的共享会话                  │
│   └─ 📁 用户自建文件夹 - "周报汇总"          │
│   [查看全部 >]  ← 点击展开右侧面板全量列表   │
├─────────────────────────────────────────────┤
│ 📂 工作空间（仅用户自建文件夹）              │
│   ├─ 📁 项目 A                              │
│   │    └─ 会话 1 / 会话 2                    │
│   ├─ 📁 项目 B                              │
│   └─ ➕ 新建文件夹（手动创建）              │
│   [查看全部 >]                               │
├─────────────────────────────────────────────┤
│ 👤 用户头像 + 🔔 消息通知（含未读角标）      │
└─────────────────────────────────────────────┘
```

### 3.2 三大核心变更

#### 变更 ①：取消"默认文件夹" + 系统文件夹
- **现状**：每个新会话自动归档到「默认文件夹」
- **方案**：新会话直接进入"最近"列表，**不创建任何文件夹**；只有用户手动"新建文件夹"时才出现文件夹
- **收益**：消除 90% 无意义文件夹；新用户进来看到的是"最近 5 条"而不是"默认文件夹下几十个会话"

#### 变更 ②：任务 / 自动化 / 订阅不再建文件夹
- **现状**：每个任务、每个定时提醒各建一个文件夹
- **方案**：
  - **任务**：平铺在「任务中心」独立模块（不在左侧会话列表展示）；如需关联会话，用"会话内任务卡片"而非文件夹
  - **自动化 / 订阅**：平铺在「订阅/自动化」独立模块；有新消息时以 🔔 红点 + 时间标签形式出现在"最近"列表（权重低于用户操作）
  - **会话**：保持为会话，不与任务/自动化混建文件夹
- **收益**：文件夹数量从 O(N) 降到 O(用户主动创建)；任务/订阅有专属视图，不污染会话列表

#### 变更 ③：活跃排序算法（用户操作 > 系统动态）

| 权重 | 触发事件 | 排序加分 | 示例 |
|---|---|---|---|
| 1.0 | 用户主动发送消息、编辑、重命名、置顶 | +100 | 刚刚回复了会话 A |
| 0.8 | 协作人 @ 我、协作邀请进入共享会话 | +80 | 陈冰在共享会话中 @ 我 |
| 0.6 | 订阅/自动化产生新消息 | +60 | 9 点提醒"喝水"推送 |
| 0.4 | 其他用户操作该会话（协作场景） | +40 | 同事在共享会话里追加内容 |
| 0.2 | 仅时间衰减（无任何新消息） | -1/天 | 7 天无新消息默认折叠 |

展示规则：
- **最近列表**：默认 5 条，按加权分倒序；超出部分收起到"查看全部"
- **置顶会话**：独立置顶区（参考 codeX），权重最高，不随时间衰减
- **7 天无新消息**：自动从"最近"移到"历史"，仅在右侧面板"全部"可见

### 3.3 新消息提醒（对标飞书 aily）

| 场景 | 提醒形式 |
|---|---|
| 订阅/自动化产生新推送 | 会话条目右侧出现 🔔 红点 + "新" 标签 |
| 协作人 @ 我 | 条目高亮蓝边 + "@我" 徽章 + 未读数 |
| 协作会话有新消息（未 @ 我） | 条目右侧显示未读数（如 ● 3） |
| 自己发起的会话 AI 回复完成 | 条目短暂出现绿色完成角标，3 秒后消失 |
| 任务/自动化失败 | 条目右侧出现 ❗ 红感叹 |

> 参考飞书 aily 的 IM 强提醒（图 1），但**收敛到左侧面板**，避免满屏打扰；仅"被 @ 我"和"任务失败"才做系统级通知。

## 五、与既有问题的对应修复

| 既有问题 | 本方案对应解法 |
|---|---|
| 缺少科学的折叠机制（许娇） | 按"今天/本周/更早"时间分组折叠，7 天无消息自动折叠 |
| 会话标题过长 | AI 自动摘要（≤20 字），超出用"..." + 悬停显示完整 |
| 缺少会话置顶 | 新增 📌 置顶区（参考 codeX） |
| 新建会话时不能就地新建文件夹 | 取消默认文件夹后，新建会话直接进入"最近"，不强制创建文件夹 |
| 历史会话内容不同步 / 问题重复 | 数据层统一治理：会话消息以服务端为准，本地仅做缓存同步 |
| 系统自动创建多余会话 | 明确"会话 ≠ 任务 ≠ 自动化"，各自独立存储，不再相互衍生 |

## 六、与任务 / 自动化 / 订阅的协同

| 模块 | 在左侧面板的位置 | 展示形态 |
|---|---|---|
| 任务 | 不在会话列表展示；独立入口在顶部栏"任务" | 任务卡片在相关会话内可见 |
| 自动化 | 出现在"最近"列表（有新消息时） | 单行条目：🤖 自动化名 · 新消息 + 红点 |
| 订阅 | 出现在"最近"列表（有新推送时） | 单行条目：🔔 订阅名 · 时间 + 红点 |
| 会话 | "最近" + "工作空间" + 右侧全量 | 主体，按活跃排序 |

> **核心原则**：任务/自动化/订阅**不建文件夹**，只在会话列表中以"活跃事件"形式出现；它们有各自的专属视图（任务中心、自动化中心、订阅中心），左侧面板只做"有新动态时提醒"。

## 七、迁移与兼容

| 阶段 | 动作 | 影响 |
|---|---|---|
| **Phase 1（1~2 周）** | 取消"默认文件夹"，新会话不再自动归档；已有"默认文件夹"内的会话保留，但不再新写入 | 新用户体验立刻改善 |
| **Phase 2（2~3 周）** | 上线"最近 / 工作空间"双区 + 置顶 + 未读红点 | 核心交互落地 |
| **Phase 3（3~4 周）** | 任务/自动化/订阅去文件夹化；右侧面板"全部"视图上线 | 彻底解决文件夹爆炸 |
| **Phase 4（持续）** | 历史会话数据一致性治理（消息重复、自动新建会话）；AI 标题摘要 | 长期体验打磨 |

## 八、关键指标预期

| 指标 | 当前 | 优化后 |
|---|---|---|
| 左侧平均文件夹数 | 20+（含大量自动创建） | ≤ 5（仅用户主动创建） |
| 找到目标会话的点击次数 | 3~5 次（翻文件夹） | 1~2 次（最近 / 搜索） |
| "系统又建了个会话"类工单 | 存在（P0） | 归零 |
| 新消息感知率（订阅/自动化/@我） | 低（需自己点开看） | 高（红点 + 角标 + 可选系统通知） |

---

## 九、一句话总结

> **把"左侧会话列表"从"所有文件夹的平铺"重构为"最近活跃 + 用户自建"双区模型**：取消系统默认文件夹、取消任务/自动化/订阅的文件夹衍生，让它们以"活跃事件"形式出现在"最近"中；新增置顶区、未读红点、时间分组折叠；想看全部点"查看全部"进入右侧面板——从而让高频项一目了然、低频项可隐藏、新消息强提醒。
